# Security policy

## Reporting a vulnerability

Please report security issues through **[GitHub Security Advisories](https://github.com/ravindu-ranasinghe/umn-discord-verification/security/advisories/new)** for this repository (private reports are supported when the feature is enabled on the repo).

If you cannot use GitHub, email the maintainers with the subject line `Gopherfy security` and include steps to reproduce and impact; do not disclose publicly until we have acknowledged receipt.

## Supported versions

| Version                        | Supported |
| ------------------------------ | --------- |
| Latest `main` / default branch | Yes       |
| Older tags or forks            | No        |

## Disclosure timeline

We aim to **acknowledge** valid reports within **7 days** and to ship a **fix within 90 days** of acknowledgment, coordinated with you on disclosure. We credit researchers in release notes unless you request anonymity.

## Scope

In scope: this repository, the Discord bot, OTP HTTP service, and deployment configuration shipped here. Out of scope: third-party services (Discord, Resend, GCP) — report those via their own channels, though we appreciate a heads-up if Gopherfy is affected.
